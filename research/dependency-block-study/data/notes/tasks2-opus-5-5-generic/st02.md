## Library APIs may have changed since your training data

Your knowledge of library APIs may be out of date. The versions pinned in `pyproject.toml` may have been released after your training data was collected, and between releases functions, classes, parameters, default values and import paths can be renamed, moved, changed or removed. Before using an API from an installed package, check its signature in the installed source (the package's files in `.venv`) or with `help()`, and write code for the version that is installed, not the version you remember. If a call fails with an import, attribute or argument error, or a deprecation warning appears, look up the installed API before trying another guess. This applies to every third-party package, including ones you know well. Where the installed code conflicts with what you remember, follow the installed code.
